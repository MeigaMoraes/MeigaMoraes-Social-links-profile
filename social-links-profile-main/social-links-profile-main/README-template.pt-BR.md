### Captura de tela

![](./screenshot.jpg)

Adicione uma captura de tela da sua solução. A maneira mais simples de fazer isso é usar o Firefox para visualizar seu projeto, clicar com o botão direito na página e selecionar "Take a Screenshot". Você pode escolher uma captura de tela de altura completa ou uma recortada, dependendo do tamanho da página. Se a página for muito longa, pode ser melhor recortá-la.

Como alternativa, você pode usar uma ferramenta como o [FireShot](https://getfireshot.com/) para capturar a tela. O FireShot tem uma opção gratuita, então você não precisa comprar nada.

Em seguida, recorte/otimize/edite a imagem como preferir, adicione ao seu projeto e atualize o caminho do arquivo na imagem acima.
